SKADI Privacy Policy

Last updated: 2026-10-21

Policy URL: https://arthoriouss.github.io/skadi-releases/privacy/

1. About SKADI

SKADI is an independent, unofficial media-client application that connects to media servers and accounts selected by the user, including Plex, Jellyfin, and Emby. SKADI does not provide or host the user's media library and does not create a SKADI cloud account.

2. Data stored on your device

SKADI stores information needed to operate the app locally. Depending on the features you use, this can include:

  • a randomly generated app/device client identifier;
  • registered media-server names, identifiers, addresses, and connection state;
  • local SKADI profiles and their server/user bindings;
  • home, library, playback, subtitle/audio, watchlist, and other preferences;
  • local collections and playback-source history;
  • authentication tokens and provider sessions in the platform's secure storage;
  • downloaded/offline media and download metadata when you use downloads.

This device-local information is not uploaded to a SKADI account service, because SKADI does not operate such an account service.

3. Connections to Plex, Jellyfin, and Emby

When you connect a provider or server, SKADI sends requests directly from your device to the provider/service or media server you selected. These requests can include authentication information, account/server identifiers, searches, library requests, playback state, watched/resume state, and media playback requests needed to perform the actions you request.

Plex, Jellyfin, Emby, Emby Connect, and independently operated media servers have their own data practices and policies. SKADI is not affiliated with or endorsed by those services.

Self-hosted media servers can be configured with HTTP or HTTPS. If you choose an http:// server address, traffic to that server may not be encrypted. Prefer HTTPS whenever your server supports it.

4. Optional crash reporting

SKADI can send technical crash and diagnostic reports to Sentry, a service provider used to diagnose crashes and improve app reliability.

On a fresh installation, crash reporting is off by default. SKADI sends these reports only after you affirmatively enable crash reporting in the app's privacy settings. You can disable future reporting at any time. In LG webOS beta builds, the app asks once, on the first Home screen, whether to turn reporting on; the answer is stored and both switches remain in Settings › Privacy.

The app configures Sentry to avoid default PII and disables performance tracing, HTTP breadcrumbs, failed-request capture, and automatic session tracking. Before a report is sent, SKADI removes event user/request/server fields and filters tokens, authorization/cookie values, URLs, hosts, e-mail addresses, usernames, private addresses, and user filesystem paths from app-provided diagnostics.

Crash reports can still contain technical information such as stack traces, app/release information, operating-system/device diagnostics, and network-level metadata needed to deliver the report.

Sentry retention for this project: reports are kept for 30 days, then deleted automatically.

Optional TV playback compatibility reports

On supported TVs (Android TV / Fire OS and LG webOS), SKADI can send a technical summary when a playback session ends. This is off by default and requires first enabling crash reports and then separately allowing playback compatibility reporting. Both preferences can be disabled.

The report can contain the TV model and operating-system version (Android API level, or webOS and browser-engine version, firmware and SDK on LG webOS), video/audio/subtitle format metadata, resolution, HDR, declared playback strategy, first-frame timing, session duration, outcome and stop reason, dropped frames, rebuffering and audio-underrun counters. On LG webOS it also includes the media provider type, playback attempt counts, media error codes, and the results of checks of which formats the TV can decode. One capability report is sent per TV and app version.

App-authored attributes do not contain titles, server names or addresses, URLs, file paths, tokens, user names or e-mail addresses. Unknown device model strings and unknown codecs are replaced by generic values.

IP addresses: the SKADI Sentry project has "Prevent Storing of IP Addresses" enabled, so client IP addresses are not stored with reports. Reports are kept for 30 days.

Windows and Linux

Crash reports and playback compatibility reports are opt-in and off by default; they are two separate choices, limited to technical data as described above.

5. Advertising, sale of data, and tracking

The audited Fire OS application does not include an advertising SDK, does not use an advertising ID for targeted advertising, and does not sell personal data.

SKADI does not run a general user-behavior analytics or advertising-tracking pipeline in the audited Fire OS build.

6. Removing local data

You can remove the currently stored provider account from the device using SKADI's account/session controls. This clears session-owned local credentials and related local session data.

Local SKADI profiles can also be managed in the app, subject to the app's profile-safety rules.

Downloaded/offline media is managed separately and may need to be removed from the Downloads area or by clearing/uninstalling the app.

Removing a provider account from SKADI does not delete the provider account itself. For example, a Plex authorization can remain in Plex Authorized Devices until it is removed through Plex.

7. Crash-report deletion

Disabling crash reporting stops future optional reports. It does not by itself delete historical reports already processed by Sentry.

Deletion requests: write to skadiapp.support@gmail.com. Matching diagnostic data is deleted within 30 days.

8. The problem-report page

The page at arthoriouss.github.io/skadi-releases/report/ is opened when you choose "Report a problem" in the app (on TV by scanning a QR code). The link contains technical details such as app version, build, platform, device model, operating system and server types (Plex, Jellyfin, Emby), so the report can be prefilled. The page uses no external scripts, fonts or trackers, and sends nothing by itself.

What you then submit goes where you choose:

  • GitHub: the report becomes a public issue on the arthoriouss/skadi-releases repository, under your GitHub account. GitHub's own privacy statement applies.
  • Tally form: the report is private to the developer. Tally acts as the form provider and its own privacy policy applies. If you give an e-mail address, it is used only to follow up on your report.

Please do not include server addresses, tokens, passwords or other personal data in a report.

9. Children

SKADI is a general media-server client. It is not directed to children under 13, and SKADI does not knowingly collect any data from children.

10. Changes

This policy is updated whenever SKADI's data practices, SDKs, provider integrations, or support/deletion processes materially change. The "Last updated" date above shows the latest revision.

11. Contact

Support: GitHub issues or the report page.

Privacy contact: skadiapp.support@gmail.com
